# Excel_Dashboard_Project_1
## 📊 Overview
This repository presents an interactive Excel dashboard, **Data Science Salary Calculator**, developed from a structured dataset of job titles, locations, and job posting sources.  
The dashboard provides a reproducible framework for analyzing salary ranges, employment types, and geographic distribution across data science and related professions.

## 🎯 Research Objectives
- Quantify salary variation across job roles in the data science ecosystem.
- Compare compensation by employment type (full-time, part-time, contractor, temporary).
- Map geographic differences in salaries using integrated visualization tools.
- Identify dominant job platforms and their contribution to employment trends.

## 📂 Repository Contents
- **Excel_Dashboard_Project_1.xlsx** → Interactive Excel dashboard with filters, charts, and summary metrics.
- **jobs.xlsx** → Source dataset containing job titles, locations, and job posting platforms.
- **README.md** → Documentation for repository usage and research context.

## 🛠️ Dashboard Features
- **Interactive filters** for job title, country, and employment type.
- **Salary distribution charts** by role and employment category.
- **Geographic visualization** via Bing Maps integration.
- **Summary indicators**:
  - Median Salary  
  - Top Job Platform  
  - Job Count
